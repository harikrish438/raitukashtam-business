# raitukashtam-business

Business/domain services for the Raitukashtam platform. Split out from the
[raitukashtam](https://github.com/harikrish438/raitukashtam) platform repo
so each domain service can be built, deployed, and redeployed independently
of platform infrastructure (discovery, config server, api-gateway, auth).

See `CLAUDE.md` for full context.
